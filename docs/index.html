۳۶ انیمیشن، تنها با یک کلیک

حال‌وهوای صفحه را عوض کنید.

یک افکت انتخاب کنید، سپس با دکمه خورشید و ماه تغییر پوسته را ببینید.

برای پیش‌نمایش Circle Reveal کلیک کنید.

۱

بومی مرورگر

با استفاده از رابط View Transitions مرورگر اجرا می‌شود.

۲

دسترس‌پذیر

در صورت ترجیح حرکت کمتر، پوسته بدون پویانمایی تغییر می‌کند.

۳

آماده برای پوسته

همه افکت‌های موجود را روی یک چیدمان واقعی امتحان کنید.

مرورگر شما از View Transitions پشتیبانی نمی‌کند؛ پوسته بدون پویانمایی تغییر خواهد کرد.

حرکت کمتر در دستگاه شما فعال است؛ پوسته بدون پویانمایی تغییر خواهد کرد.
